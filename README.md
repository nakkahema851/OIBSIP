# Number Guessing Game 🎯

## Task 2 – Java Development Internship

A simple console-based Number Guessing Game developed using Java as part of the **Oasis Infobyte Java Development Internship**.

## 📌 Project Description

The game generates a random number between **1 and 100**. The player has a maximum of **7 attempts** to guess the number.

After each guess, the game provides a hint:

- **Too Low!** – The guessed number is smaller than the secret number.
- **Too High!** – The guessed number is greater than the secret number.
- **Correct!** – The player has guessed the number successfully.

The game also includes:

- Attempt counter
- Maximum 7 attempts per round
- Score calculation
- Total score tracking across multiple rounds
- Play Again option
- Input validation
- Final score display

## 🛠️ Technologies Used

- Java
- Java `Random`
- Java `Scanner`
- Visual Studio Code
