# Number Guessing Game

## Project Description

The Number Guessing Game is a Java console-based game where the computer generates a random number between 1 and 100. The player has a maximum of 7 attempts to guess the correct number.

After each guess, the game provides a hint such as **Too High** or **Too Low**. If the player guesses the number correctly, the game displays the number of attempts used and the score.

The player can also play multiple rounds, and the total score is maintained across rounds.

## Technologies Used

* Java
* Java Random
* Java Scanner
* Visual Studio Code

## Features

* Random number generation from 1 to 100
* Maximum of 7 attempts per round
* Too High / Too Low hints
* Correct answer detection
* Attempts remaining display
* Game Over message
* Play Again option
* Round score
* Total score across multiple rounds
* Final score display
* Input validation

## How to Run

1. Open the project in Visual Studio Code.
2. Open `NumberGuessingGame.java`.
3. Compile the program:

```bash
javac NumberGuessingGame.java
```

4. Run the program:

```bash
java NumberGuessingGame
```

5. Enter a number between 1 and 100 when prompted.
6. Follow the hints to guess the correct number.
7. Choose `yes` or `no` when asked whether to play again.
